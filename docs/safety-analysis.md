# 编辑后的安全分析

`computeSafety` 保留原来的规则、排序和同步函数接口；一次检查通过 `withPlacementSnapshot` 共享几何查询。不同快照重新核对，避免在替换模型、改变管件顺序或恢复撤销状态后继承旧判定。

已安装的平面攀爬网仍使用同一套候选构造、固定点、支撑引用及姿态比较。搜索先按原位置缩小范围，并保持原候选顺序及去重语义。搜索余量为1厘米，最终位置判定仍为0.1厘米；余量覆盖候选坐标去重的舍入误差，不放宽安装约束。普通安装候选枚举不传入位置条件，继续取得完整结果。

界面中的全模型检查由 `safety.worker.ts` 执行。Worker先加载相同目录和原生碰撞网格，再读取模型并调用 `computeSafety`。管件放置时原有的即时安装和碰撞拦截继续同步执行；安全分析不决定是否接受一次放置。

`SafetyQueue` 最多持有一个正在计算的快照和一个最新等待快照。新的请求取消过期等待者；过期结果不能确认当前模型。完整模型内容、房间选项、账户及标签构成结果绑定，最多缓存四个完整结果。账户或标签变化时释放旧队列、Worker及缓存。失败、超时或资源读取错误保持失败状态，用户可以重试；关闭工作区时结束等待者并释放Worker。

界面只展示当前绑定的结果。等待时安全面板显示检查状态；失败时显示重试入口。旧风险数量和旧的完成标记不会作为当前结果保留。这个异步状态不改变最终的安全检查内容，也不表示产品或实物已经通过安全认证。

验证包括已安装网与完整候选枚举对照、固定点损坏、支撑缺失、连续框边、位置容差、重合管、管件重排、模型替换、房间变化、旧响应、失败恢复及资源释放。实际模型和鼠标加管测试由 `scripts/verify-add-performance.mjs`、`scripts/verify-safety-equivalence.mjs` 与 `scripts/verify-safety-runtime.mjs` 读取调用者提供的本地JSON，不在仓库中保存用户模型。
