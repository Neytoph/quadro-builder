# 绑带支撑检查

`computeSupportGraph`仅服务于安全提示，沿实际节点、45度连接臂、管夹连接及有效近距绑带追踪组件。该图不写入存档、不改变管子的几何和引用，不用于刚性组选取、移动或旋转。

绑带需要为当前版本组件，两根真实管和参数挂点均存在，角色、宽度、安装朝向与实际几何一致。两挂点的中心距离不超过管径加带宽时，计入近距固定连接；当前目录为4.9+5=9.9厘米。这是模型的几何检查规则，不是实物承载认证。远距离绑带仍可放置、保存和显示，但不作为两根管已经近距固定的依据。弯管使用圆弧上的实际挂点。

图中没有凭空产生的地面锚点。两组悬空结构互绑、多级绑带闭环仍会报告缺少支撑；只有沿连接追踪到地面才消除对应的悬空提示。配件安装损坏、平台缺边、护栏、坠落高度、倾覆和未验证承载能力等检查分别保留。普通组合搭建绳不在本次绑带的近距固定规则内。

安全检查不再把15厘米内的两个独立接头直接当作相连。轮子／轴承原有离地豁免只作用于其所在组件，其他位置的管夹也不会使整个模型跳过悬空检查。原有地面判定口径保持。

节点原生保存精度为0.01厘米，绑带端部留距检查接受同等精度的几何误差，避免斜管端部默认挂点保存后失效；大于该精度的越界仍拒绝。

绑带是布带，面板可覆盖它。普通板的精细放置复核及共享装配路径均允许板与绑带重叠，两种安装顺序采用同一规则；真实管子、接头、其他硬件及重复硬板仍检查碰撞。绑带的有效挂点与支撑检查单独保留。

`strapSupport.test.ts`覆盖地面追踪、悬空闭环、远距离、损坏挂点、直／斜／弯管、刚性组隔离、删除与历史、原生／Yjs重读及平移。真实账号模型的调整、读回和支撑对照证据单独保存在本机任务目录；测试夹具不代表实物验收。
