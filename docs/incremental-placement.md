# 安装位置增量计算

`Builder.refresh()` 在只读计算阶段进入 `withPlacementPass`。模型入口 `panelAccessoryMounts`、`confirmedMounts`、`accessoryMounts` 和 `tubeFittingSpots` 也可独立进入该阶段。缓存保存在按模型实例区分的 WeakMap 中，不进入模型 JSON、Yjs 或用户存档。

每次计算先比较零件内容和承载节点，保留变更前、变更后的空间范围。新增、删除、移动、原地修改、`loadJSON`、撤销重做与协作载入共用同一失效规则。普通空间查询只重新检查与变更范围相交、或引用同一支撑的候选；无有效范围的记录保守失效。原生网格已加载时，失效范围同时覆盖实际装配包围体。目录几何与网格加载状态变化会清除旧缓存。

连续短管组成的框边及吊环支撑保留沿轴线的依赖，避免把远处同线支撑误认为无关。接管计划的键包含目标附近节点与起点的连通关系；连接或拆开远处桥接管，可能改变闭环吸附，必须重新核对。全局连接关系仍在结构变化后重新建立。

板材 Worker 保留同一模型实例，加载新快照后仅使相关候选失效。主线程在等待结果时保留仍有效的安装点；附近可能受影响的点暂时隐藏，后台结果按请求编号与完整快照核对后才接收。安装提交继续使用原有实时验证。

候选缓存也保存不可安装结果，障碍删除后这些结果同样失效。返回值与缓存值分离，调用方修改候选或安装记录不会污染后续查询。缓存有容量上限；超限只影响复用率，不改变安装规则。

范围是安装位置的几何与碰撞计算。轻量枚举、模型快照、历史提交、物料及场景绘制仍沿用原有流程；没有改变文件格式、安装规则或界面操作。

回归：`src/engine/incrementalPlacement.test.ts` 用真实模型 API 比较增量结果与新模型完整计算。浏览器验收通过 `node scripts/check-incremental-placement.mjs <原生模型.json> <证据目录> <本地地址>` 执行，使用 Chrome、真实 WebGL、Worker 和 Builder 安装／删除／历史入口。测试隔离副本，不连接用户原模型写入。
