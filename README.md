# Quadro Builder

QUADRO 攀爬架的浏览器 3D 设计器。打开网页就能按官方网格搭，搭完能出料表、对库存、导出拼装说明书。`.qdf` 能和原厂软件互相打开。

QUADRO 是原厂商标。这是非官方社区工具，和 QUADRO GmbH 没有关系。

## 想解决什么

搭攀爬架时，真正卡住的往往不是「有没有零件」，而是工具不好用、搭完没法教别人、家里的存货对不上号。

| 痛点 | 现在怎么处理 |
| --- | --- |
| 搭建工具别扭，为改一稿还得装桌面软件 | 浏览器里接管子、接头、板、轮、布、滑梯、泳池。顶栏选零件，点高亮位置就能装上 |
| 造型搭出来了，别人不知道从哪一步下手 | 「文件 → 导出拼装说明书」按真实搭建顺序出 PDF，每步正面、背面各一张，并列出本步零件 |
| 库存散在脑子里，不够了才发现缺件 | 右栏「我的库存」记数量；「选购建议」按官方件对照当前造型，看缺什么、该买哪套 |
| 配件种类多，管子、接头、螺丝、加固混在一起 | 「零件清单」按类列出，点一行会在场景里标出对应零件 |
| 界面挤、对话框多，搭着不顺手 | 工作台按常用操作排：顶栏工具、左栏颜色、右栏文件和清单；中 / EN / DE |
| 现成造型少，做好的架子不好给别人 | 「模型库」里有官方造型和起步示例；自己的设计可存在「我的设计」，也可「复制分享链接」让对方打开即见 |
| 共享社区 | **待建设**。现在只有链接分享，没有公开的作品墙、评论或协作 |

界面按 [vokako/quadro-3d-designer](https://github.com/vokako/quadro-3d-designer) 重做；搭建、QDF、料表、官方网格用的是 [thecodingdad/quadro-3D](https://github.com/thecodingdad/quadro-3D) 的引擎。两边都是 MIT。本项目**不是**把 designer 整仓拷过来当底座，3D 也不是 React Three Fiber。

## 功能

**搭建**

- 管、连接件、面板、轮、布件、泳池、滑梯、加固，按官方网格吸附
- 经典四色和 Home 柔和色；一键按家族换色，或全部改成同色
- 选择、框选、整块选择、复制粘贴（可升降楼层）、旋转、删除
- 多标签：同时开几个设计，未保存的会标出来

**模型库**

- **官方**：约 495 个官网造型，卡片是空背景 3D 图。第一次打开某条会从官网下 QDF，之后缓存在本机
- **起步造型**：立方框、长方、塔、桌、隧道、金字塔等。单体挂到指针上再放下；金字塔会整份替换当前设计（可撤销）
- **我导入的**：批量读入本地 `.qdf` 文件夹或单文件

**对账和选购**

- **零件清单**：管子、接头、板、布、滑梯、轮、配件、加固、螺丝。点一行，场景里对应件会高亮
- **我的库存**：手填数量，可导入 / 导出库存 JSON
- **选购建议**：当前造型映射到官方件后，看缺什么、哪套能盖住、最省的是哪套；可复制购物清单。中文界面套装价按人民币显示

**视图和房间**

- 草地 / 天空可开关（左上第一个按钮）
- 「框住」把模型收进镜头（F）
- 房间边界和尺寸线：宽、深、高可改；超尺寸只在右栏警告，不拦住搭建
- 右下角视角方块可快速改朝向

**导出和分享**

- 拼装说明书 PDF：封面成品图、每步正反两张、本步零件、总料表
- 导出 / 导入 `.qdf`（和原厂软件互开；Home 色导出会落到官方红绿蓝黄）
- 导出 JSON、PNG
- 复制分享链接：设计写进网址，对方打开即见，不用账号
- 「我的设计」保存在本机浏览器里

**其它**

- 首次打开有五步引导，「文件」里可再看一遍
- 界面中 / EN / DE
- 可安装成 PWA，离线还能打开已经缓存过的页面（官方模型第一次仍要联网下载 QDF）

## 使用流程

第一次打开会弹出引导。跳过之后也可以从「文件 → 再看一遍引导」回来。

1. **起手**  
   打开右栏「模型库」。  
   - 想改现成架子：官方里点卡片，或把卡片拖到画布上。第一次打开该造型需要能访问官网（开发时走本地代理）。  
   - 想从简单形状开始：切到「起步造型」，点立方框、塔、桌等。单体跟指针走，点画布放下；金字塔会替换当前画布。  
   - 想从零搭：顶栏选「管」，空场景点一下，原点会长出第一根。

2. **搭建**  
   顶栏选零件，点场景里高亮的箭头或位置装上。左栏改颜色。接错了用撤销，或按 D 进删除模式点掉。需要搬一整块时：双击或按 L 选中相连零件，⌘C / ⌘V 复制，↑↓ 调高度，再点击放下。

3. **看尺寸、对库存**  
   「文件」里打开房间边界，填家里能摆下的宽深高。右栏「零件清单」看用了什么；「我的库存」填手里的数量。「选购建议」会告诉你还缺哪些件、该买哪套。

4. **预览怎么搭**  
   点底部「逐层拼装」（或按 A），按真实顺序一步步显示。`[` `]` 翻步，可改从哪一侧开始（自下而上、沿 X / Z）。Esc 回到选择。

5. **留下结果**  
   ⌘S 存进「我的设计」。要给别人搭：左上「导出拼装说明书」，或「文件」里同一项。要给别人改：复制分享链接，或导出 `.qdf`。只要自己看：导出 PNG。

标签栏可以同时开多个设计。关掉未保存的标签前会问一次。

## 界面

| 位置 | 做什么 |
| --- | --- |
| 顶栏 | 选择、删除、管、面板、连接件、轮、布件、泳池、滑梯、加固 |
| 左栏 | 颜色、一键换色 |
| 左上三个按钮 | 草地、框住模型、导出说明书 |
| 画布上方 | 设计标签 |
| 右栏 | 文件、我的设计、模型库、选购建议、零件清单、我的库存 |
| 底栏 | 逐层拼装 |
| 左下角 | 当前模式能用的快捷键，点标题可收起 |

窗口变窄时，左栏和三个按钮会落到工具栏下面，避免叠在一起。

## 怎么搭

1. **管**：选长度后点接头上的箭头，往空方向接一根。连接件会按已经接上的管子长出来。数字键 1–6 换管长（15 / 25 / 35 / 10 / 20 / 75 cm）。
2. **连接件**：空场景会直接落在原点。已经有结构时，只高亮还能套上所选型号的现有接头（还要留得下空插座）。点一下换成该通型，再点可转动空插座；不会在空气里的网格邻点长新节点。Esc 或换工具退出。
3. **面板**：先点一根承重管（琥珀色），再点对面那根绿色的。
4. **滑梯**：选官方四种之一，点挂钩或滑梯链位置。
5. **轮 / 布 / 泳池 / 45° / 双管 / 管夹 / 孔锁 / 柔性接头**：从顶栏拿出，吸到高亮点上。
6. **加固**：点两根共线的 35 cm 管，插入 80 cm 木芯。
7. 底部 **逐层拼装** 按真实搭建顺序显隐；`[` `]` 翻步。搭完可导出拼装说明书 PDF。

`.qdf` 从「文件」导入或导出，可与原厂软件交换。官方网格和特殊件用 JSON 保真。

### 常用操作

快捷键按系统显示：Mac 用 ⌘，Windows 用 Ctrl。

| 操作 | 键 |
| --- | --- |
| 撤销 / 重做 | ⌘Z / ⇧⌘Z（Windows：Ctrl+Z / Ctrl+Y） |
| 保存 | ⌘S |
| 全选 | ⌘A |
| 复制 / 粘贴 | ⌘C / ⌘V。粘贴后 ↑↓ 升降，点击放下，Esc 取消 |
| 选择整块 | 双击，或 L，或左栏「选择整块 L」。Shift/⌘ 加点选 |
| 旋转选中 | Q 逆时针 / E 顺时针 |
| 删除模式 | D。点零件逐个删除，Esc 或再按 D 退出 |
| 删除选中 | Delete / Backspace |
| 框住模型 | F |
| 逐层拼装 | A，`[` `]` 翻步 |
| 退出当前模式 | Esc |

当前模式下能用的键会列在左下角，点标题可以收起。

相机：拖动旋转；Mac 用 ⌥ 拖或 ⇧+双指横移、双指缩放；Windows 用 Alt 拖或 Shift+滚轮横移、滚轮缩放。

界面语言在「文件」里切「中 / EN / DE」。

## 本地运行

需要 Node 22+ 和 [pnpm](https://pnpm.io/)。本机若用 Homebrew 的 `node@24`：

```bash
export PATH="/opt/homebrew/opt/node@24/bin:$PATH"
pnpm install
pnpm dev
```

浏览器打开终端里打印的地址，一般是 `http://localhost:5173/`。端口被占用时 Vite 会顺延。

```bash
pnpm exec tsc -b --noEmit   # 类型检查
pnpm build                  # 产出 dist/
pnpm preview                # 预览生产包
```

打开官方模型时，开发服务器会把 `/mdb-files` 代理到 `https://mdb.quadroworld.com`。缩略图在本仓库 `public/thumbs/`，不走官网。
